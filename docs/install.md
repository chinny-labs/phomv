# Install

## Homebrew (macOS / Linux)

```sh
brew install chinny-labs/tap/phomv
```

Or, equivalently:

```sh
brew tap chinny-labs/tap
brew install phomv
```

> **Moved from `phomv/tap`?** The tap now lives in `chinny-labs`:
> `brew untap phomv/tap && brew install chinny-labs/tap/phomv`.

The formula lives in [`chinny-labs/homebrew-tap`](https://github.com/chinny-labs/homebrew-tap)
and is regenerated by GoReleaser on every tagged release.

## Windows (winget)

```sh
winget install phomv.phomv
```

Manifests are published from
[`chinny-labs/winget-pkgs`](https://github.com/chinny-labs/winget-pkgs) (a fork of
`microsoft/winget-pkgs`) and merged into the official catalog via PR.

## Pre-built binaries

Grab the latest archive for your platform from the
[releases page](https://github.com/chinny-labs/phomv/releases). Archives are built for
linux and macOS on amd64 and arm64, and Windows on amd64. Each archive also
contains shell completions (`completions/`) and man pages (`manpages/`).

## From source

Install the latest tagged release with Go:

```sh
go install github.com/chinny-labs/phomv/cmd/phomv@latest
```

Or build locally:

```sh
git clone https://github.com/chinny-labs/phomv.git
cd phomv
make build       # produces ./bin/phomv
make install     # installs into $GOBIN
make release     # cross-compiles to ./dist for linux/macOS/windows
```

Requires Go **1.24+**.

## Shell completions and man pages

Homebrew installs both automatically (v0.2.0+). Otherwise, copy them from the
release archive, or generate completions yourself:

```sh
phomv completion bash > /etc/bash_completion.d/phomv          # bash
phomv completion zsh > "${fpath[1]}/_phomv"                   # zsh
phomv completion fish > ~/.config/fish/completions/phomv.fish # fish
phomv completion powershell | Out-String | Invoke-Expression  # PowerShell
```

From a source checkout, `make docs` writes both into `./completions` and
`./manpages`.

## Verify

```sh
phomv version
```
